Opening an Algorab 6 app for the first time

Algorab 6 builds are not signed with a developer certificate, by decision. The first time you open one, your system shows a warning. This is expected. Open only builds downloaded from this site. Button names are shown in English; your system may show them in its own language.

macOS
  1. Double-click the app. macOS blocks it the first time.
  2. Open System Settings, choose Privacy & Security, and scroll down to Security.
  3. Click Open Anyway. The button is available for about an hour after the first attempt.
  4. Enter your login password and click OK.
Windows
  1. Double-click the app or installer. Windows shows a screen that says Windows protected your PC.
  2. Click More info.
  3. Click Run anyway.

On Linux, Algorab 6 is provided as an AppImage. Make the file executable, then run it.

Aureum (lightweight optimisation mod, separate download)

Aureum is a separate, independent mod. It optimises game logic, memory, and server tick cost, and deliberately never touches the chunk-render pipeline. It is not a replacement for Sodium — it optimises the side Sodium does not touch, so it is safe to run alongside it. If you want higher FPS, install Sodium separately.

Measured so far: -6.3 MB at 2,209 loaded chunks, -17.2 MB after generating a similarly sized area of new terrain (both reproduced across two independent runs). MSPT (tick time) is unchanged within measurement noise. Two client-side toggles (particle limit, block-entity render distance) ship off by default and unmeasured, because this development environment has no client. See the README on GitHub for installation and configuration. Aureum 2.0.0 adds one more, found by profiling allocations: the server's random-tick loop now creates about 98% fewer coordinate objects (about 1.3 GB down to about 0.02 GB over a 9,600-tick benchmark; a JFR estimate, two on/off pairs agree). No change in tick time or heap is claimed.

Algorab Agent

A program for the Minecraft server you host yourself: it keeps the server's mods in step with Algorab Store. It checks each download, stops the server, swaps the files, starts it again, and puts the old files back if it does not come up.
