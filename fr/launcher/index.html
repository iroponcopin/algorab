Nouveautés · Version 5.5.1311

Corvus Store 5.5.1311 and Corvus Agent 5.5.1311 bring the following.

Corvus Store now also downloads Fabric API, which Punchy! needs, straight from Modrinth when it is missing from the mods folder. This happens only when you press Install for Punchy!, and the confirmation says so. A Fabric API you already have is never touched. If Fabric API cannot be downloaded or fails its check, Punchy! is not installed and nothing is left behind.

On macOS, Corvus Store follows the system's Reduce Transparency, Increase Contrast and Reduce Motion settings while it is running, without a restart. It shows the number of available updates and the progress of a download on its Dock icon. It gives a trackpad tap as the sliders click into each step and when you choose a model. It no longer waits for a macOS permission question before its window appears.

Corvus Agent 5.5.1311 has no functional change.

Known limits: the macOS features were checked on one Mac with test instruments, not by long use. Fabric API downloading was checked with a local stand-in, not yet with a real download through the Store. Windows and Linux do not use the macOS features.

Guide

Corvus est une petite application de bureau qui maintient vos mods à jour automatiquement. Elle consulte ce Wiki pour connaître la version actuelle, télécharge les mises à jour pour vous et vérifie chaque fichier téléchargé par rapport à une somme SHA-256 publiée ici avant de toucher à votre dossier mods. Ce Wiki est la seule source à laquelle elle se fie.

Ce guide a été écrit pour les versions précédentes de Corvus. Corvus Store 3.0 a de nouveaux écrans ; certaines étapes peuvent différer.

Ce qu'est Corvus et pourquoi il a été créé

Garder ses mods à jour à la main oblige à revenir sur la page de téléchargement, comparer les numéros de version, télécharger un nouveau fichier et le remettre dans le bon dossier à chaque version. Corvus automatise cela : il lit le manifeste des versions de ce Wiki, le compare à ce que vous avez déjà installé et ne récupère que ce qui a changé.

Chaque téléchargement du lanceur est vérifié par rapport à une somme SHA-256 publiée par ce Wiki avant d'être utilisé. Si un fichier téléchargé ne correspond pas, le lanceur ne l'installe pas. Ce Wiki est la seule source de vérité du lanceur pour savoir quelle est la version « actuelle ».

Comment installer Corvus

Corvus est disponible sur la page de téléchargement de ce Wiki sous deux formes :

  • Des programmes d'installation natifs, un par système (.msi pour Windows, .dmg pour macOS, .deb pour Linux) — ils s'installent comme n'importe quelle application de bureau et ne demandent pas Java. Comme ils ne sont pas encore signés, votre système affiche un avertissement au premier lancement. Sous macOS, faites un clic droit sur l'application et choisissez « Ouvrir » plutôt que de double-cliquer. Sous Windows, dans l'avertissement SmartScreen, choisissez « Informations complémentaires » → « Exécuter quand même ».
  • Le jar multiplateforme corvus-5.5.1311.jar — ce seul et même fichier fonctionne aussi bien sous Windows que sous macOS ou Linux, mais Java 25 ou une version plus récente doit être installé au préalable. S'il ne s'ouvre pas par un double-clic, ouvrez un terminal (ou l'invite de commandes) dans le dossier de téléchargement et exécutez java -jar corvus-5.5.1311.jar.
Désigner un dossier de pack de MODs existant

Si vous avez déjà installé des mods à la main, inutile de tout recommencer. Au premier lancement, le lanceur vous laisse choisir le dossier où se trouvent déjà vos mods au lieu d'en créer un nouveau. Indiquez votre dossier mods existant et le lanceur traitera cette installation comme celle qu'il gère désormais.

Différence entre mode de mise à jour automatique et manuel

En mode de mise à jour automatique, le launcher consulte lui-même les informations de publication de ce Wiki et installe les nouvelles versions dès leur parution. Votre dossier de pack reste ainsi toujours à jour sans que vous ayez quoi que ce soit à faire.

En mode de mise à jour manuelle, le launcher vérifie bien s'il existe une mise à jour, mais attend votre confirmation avant de télécharger ou d'installer quoi que ce soit. C'est pratique quand vous voulez choisir vous-même le moment d'une mise à jour, par exemple pour éviter qu'elle ne s'invite au milieu d'une partie.

Comment vérifier qu'une mise à jour a bien été appliquée

Depuis la version 1.1.0, appuyer sur Update écrit les nouveaux fichiers de MODs directement dans le dossier mods du pack. Le message « Update complete » ne s'affiche pas tant que le contenu du dossier n'a pas été réellement revérifié après la mise à jour et que la présence des fichiers attendus n'a pas été confirmée. Si quelque chose échoue en cours de route, l'échec est signalé comme tel, et non masqué par un faux succès.

Comment le vérifier vous-même sous macOS : ouvrez le dossier indiqué dans la section Général (dans le Finder, appuyez sur ⌘+⇧+G puis collez le chemin), regardez à l'intérieur de mods et comparez, avant et après Update, le numéro de version contenu dans chaque nom de fichier cherry-*.jar.

Si vous mettez à jour un dossier de pack touché en dernier par un launcher antérieur à la version 1.1.0, il peut arriver, la toute première fois seulement, que l'ancien jar d'un MOD reste à côté du nouveau (les launchers plus anciens ne gardaient aucune trace des fichiers qu'ils avaient eux-mêmes déposés). Cela se règle tout seul dès la mise à jour suivante. Si cela vous gêne d'ici là, vous pouvez sans problème supprimer à la main le fichier cherry-*.jar à l'ancien numéro de version, une fois la présence du nouveau confirmée.

Restaurer depuis une sauvegarde quand une mise à jour a échoué

Au cas où une mise à jour laisserait votre pack dans un état non souhaité — un MOD qui dysfonctionne, par exemple — ou si vous voulez l'annuler, le launcher conserve en sauvegarde l'état du pack d'avant la mise à jour. Plutôt que d'essayer de réparer les fichiers à la main, utilisez la fonction de restauration du launcher pour ramener le dossier du pack à l'état de la sauvegarde.
