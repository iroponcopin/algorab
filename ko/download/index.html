Corvus 6 앱을 처음 열 때

Corvus 6 빌드는 방침에 따라 개발자 인증서로 서명하지 않았습니다. 그래서 처음 열면 시스템이 경고를 표시합니다. 정상입니다. 이 사이트에서 내려받은 빌드만 여세요. 버튼 이름은 영어로 적었으며, 시스템에서는 해당 언어로 표시될 수 있습니다.

macOS
  1. 앱을 더블클릭합니다. macOS는 처음에 차단합니다.
  2. 시스템 설정을 열고 Privacy & Security를 선택한 뒤 Security까지 아래로 스크롤합니다.
  3. Open Anyway를 클릭합니다. 첫 시도 후 약 1시간 동안 이 버튼이 나타납니다.
  4. 로그인 암호를 입력하고 OK를 클릭합니다.
Windows
  1. 앱 또는 설치 프로그램을 더블클릭합니다. Windows protected your PC라는 화면이 나타납니다.
  2. More info를 클릭합니다.
  3. Run anyway를 클릭합니다.

Linux에서는 Corvus 6가 AppImage로 제공됩니다. 파일을 실행 가능하게 만든 뒤 실행하세요.
